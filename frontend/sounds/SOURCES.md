# Interface sounds

The ten sounds of the console's interface (Settings → Sound turns them on or off).

Made by the OwneetOS project owner (fancy-dino) with FL Studio, 2026. Licence: GPL-3.0-or-later,
like the rest of OwneetOS.

The files stay as delivered (WAV, 16-bit, 44.1 kHz, stereo); the package makes them 48 kHz mono
and removes the silence at the start and at the end. Length: the sound itself, without that
silence.

| File | Plays when | Length |
|---|---|---|
| `nav-move.wav` | the selection moves | about 320 ms |
| `nav-edge.wav` | the selection cannot move further | about 220 ms |
| `nav-confirm.wav` | A, B, switches, tabs | about 220 ms |
| `nav-section.wav` | LB / RB change section | about 130 ms |
| `sheet-open.wav` | a window opens | about 150 ms |
| `sheet-close.wav` | a window closes | about 170 ms |
| `notify.wav` | a notification (news, or something to act on) | about 380 ms |
| `error.wav` | something just done failed, or cannot be done now | about 200 ms |
| `game-launch.wav` | a game or app starts | about 1.4 s |
| `startup.wav` | the interface appears after start-up | about 3.3 s |
