New in 5.6a: in a web app or the player, View (keyboard: V) opens the legend of that app's buttons, for the screen on show. gamescope: it floats over the app, which keeps working under it (move, press, go back: the legend follows the screen, e.g. Netflix's title window or player); only View closes it, and Guide closes it on the way to the home screen. cage: a full-screen page of the console; B or View goes back to the app.
Gamepad: D-pad / left stick, A, B, X, Y, Menu, LT / RT, R3, right stick, View, Guide. Keyboard: arrows, Enter = A, Esc = B, X, Y, M = Menu, Z / C = LT / RT, R = R3, Page Up / Down = right stick, V = View, H = Guide.
Demo only: 1–6 the app on screen (1 a web app, 2 YouTube, 3 Netflix, 4 Spotify, 5 a video, 6 a song), S session (gamescope), P palette, T text size, G button prompts, L language, N sounds (on).
