  • Palettes as tokensEach palette is a set of eight colors: background, surface, raised, line, text, muted, accent, text-on-accent. A theme never contains a hard-coded color.
  • High contrast is a paletteAccessibility lives in the same list as the other palettes. It is not hidden in a sub-menu.
  • Text sizeScales text only. The layout grid stays fixed so the TV safe area is respected.
TypeBricolage Grotesque for titles, Lexend for all interface text (designed for reading comfort, legible from the couch). Both open source, under the SIL Open Font License.
ScaleDesigned on a 1280 × 720 grid that scales to 1080p and 4K. 5% horizontal safe area for TVs with overscan.
FocusA double ring in the accent color plus a small lift. It must stay visible from 3 m away on every palette, including Daylight.
