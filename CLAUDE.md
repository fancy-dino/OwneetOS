# OwneetOS

All project rules, decisions and plans live in the Obsidian knowledge base, the sibling folder
`../OwneetOS-knowledge-base` (its `CLAUDE.md` is loaded by the workspace's `CLAUDE.md` one level
up). Read its guards before any work and record every decision agreed with the owner there
(`kb-rules.md`). References like `[[controller-input-map]]` in code and documents are notes
of the knowledge base. This repository's `.claude/settings.json` runs the knowledge base's hooks
(guards, reminder, indexes) when it sits next to this repository, and warns when it does not.
